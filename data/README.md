# Base de datos

`mundial_fifa_2026.sqlite` contiene la versión consolidada del proyecto.

## Cobertura

- 48 selecciones.
- 16 estadios.
- 1.248 jugadores.
- 104 partidos.
- 5.323 registros de alineaciones.
- 2.630 tiros.
- 208 actuaciones colectivas.
- 51 goles enriquecidos manualmente.

La base puede abrirse con DBeaver, DB Browser for SQLite o la herramienta `sqlite3`.
