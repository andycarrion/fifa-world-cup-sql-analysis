# Documentación

`documentacion_tecnica.docx` contiene:

- Objetivo y alcance del proyecto.
- Decisiones de diseño.
- Granularidad de cada tabla.
- Diccionario de datos campo por campo.
- Proceso de extracción, transformación y carga.
- Evolución del modelo.
- Análisis habilitados.
- DDL documentado y consultas SQL de ejemplo.

El diagrama entidad–relación se incorporará como una mejora posterior.
